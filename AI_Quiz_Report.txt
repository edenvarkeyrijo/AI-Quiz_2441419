AI QUEST — INTERACTIVE AI QUIZ GAME
Course: DSC401-6 Artificial Intelligence — Assignment

1. Objective
To design an interactive quiz game that helps students revise and assess Artificial Intelligence concepts from Units I and II.

2. Software Used
Python and Streamlit. Streamlit provides the browser-based interface and handles user input, navigation, and display of results.

3. Game Design and Working
The Home page allows the player to enter a name and select the number of questions, difficulty level, topics, randomization, and timer. Questions are displayed one at a time. The player can select an answer, request a hint, check an answer, navigate between questions, and submit the quiz. Immediate feedback and explanations support learning. At the end, the application displays the score, accuracy, and answer review. Results can be downloaded as a CSV file.

4. Question Bank and Coverage
The supplied bank contains 60+ questions covering AI foundations and applications, the Turing Test, rational and intelligent agents, agents and environments, good behaviour, environment types, problem formulation and state spaces, production systems, problem characteristics, search-program design, BFS, DFS, iterative deepening, hill climbing and variations, heuristic and best-first search, CSP, and means-end analysis. It includes multiple-choice, True/False, Assertion–Reason, fill-in-the-blank, match-the-following, real-world scenario/application, and problem-solving formats. More than 10 items use real-world scenarios, and more than 5 require search/state-space reasoning.

5. Scoring
Score = number of correct answers.
Accuracy (%) = (number of correct answers / total questions) × 100.

6. Features
Randomized questions, optional timer, difficulty and topic filters, progress indicator, hints, immediate feedback, answer explanations, final result summary, answer review, downloadable results, and a session leaderboard.

7. Conclusion
AI Quest makes revision of AI concepts interactive and provides feedback on student understanding. It can be demonstrated in class by selecting a short quiz and completing it live.
