# AI Quest — DSC401-6 Artificial Intelligence Quiz Game

## Features
- 60+ question bank, answer key and explanations
- Multiple-choice, True/False, fill-in-the-blank, Assertion–Reason, match-the-following, scenario/application and search/problem-solving questions
- Topic and difficulty filters
- Random question order
- Optional timer
- Score, accuracy, progress, hints and immediate feedback
- CSV result download and question-bank export
- Session leaderboard
- Built-in report page

## Run locally
1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the app:
   `streamlit run app.py`
5. A browser tab opens with the quiz interface.

## Deployment
Streamlit: https://ai-quiz-2441419.streamlit.app/
